# AI Model Weights

Place YOLO model weights (.pt files) in this directory.

Download instructions:
1. Run `python scripts/download_model.py` from the project root
2. Or manually download from the Ultralytics model zoo

Expected files:
- `weapon_detector.pt` - Primary weapon detection model (YOLOv8m fine-tuned)

These files are gitignored due to their large size (50-200MB).
